# Планировщик комнат

Интерактивный редактор планировки помещений: расставляйте мебель на плане в масштабе, проверяйте проходы и пересечения, выгружайте чертёж. Комнат можно завести сколько угодно — каждая хранит свою расстановку и историю отмены независимо от остальных.

**Открыть:** https://v1talii-dev.github.io/room-plans/

## Возможности

- Несколько комнат: создавайте, переименовывайте и удаляйте их через переключатель в шапке; расстановка и история отмены у каждой своя.
- План комнаты в сантиметрах с сеткой 10 см, размерами стен, дверьми и окнами.
- Перетаскивание предметов с привязкой к стенам, соседям и сетке (<kbd>Alt</kbd> — без привязки), изменение размеров и поворот ручками.
- Групповое выделение: Shift или Ctrl+клик по предметам добавляет их в группу, дальше она двигается, поворачивается, дублируется и удаляется как одно целое.
- Подсветка проблем: пересечения предметов, выход за стены, предметы в зоне открывания двери.
- Расстояния от выбранного предмета до стен и соседей, точный ввод размеров и отступов в панели.
- Каталог мебели (столы, стулья, кресла, комоды, кулер, вешалка и др.) и свои предметы с произвольным названием, формой, размерами и цветом. Свои предметы можно запомнить как шаблоны.
- Двери и окна на любой стене: ширина, положение, сторона петель, открывание внутрь или наружу.
- Отмена и повтор, горячие клавиши, масштаб колесом с <kbd>Ctrl</kbd> и щипком на телефоне.
- Экспорт: чертёж PNG или SVG (масштаб 1:50 для печати) — один и тот же чертёж с размерами и подписями, только формат разный, — и файл расстановки JSON (его же можно загрузить обратно).
- Светлая и тёмная тема, работа на телефоне.

Изменения, комнаты и настройки автоматически сохраняются в этом браузере. Чтобы перенести план на другое устройство, используйте экспорт и импорт JSON.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | сдвиг на 1 см, с <kbd>Shift</kbd> — на 10 см |
| <kbd>R</kbd> / <kbd>Shift</kbd>+<kbd>R</kbd> | поворот на 90° по / против часовой стрелки |
| <kbd>Delete</kbd> | удалить выбранное |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | дублировать |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | отменить, повторить |
| <kbd>Esc</kbd> | снять выделение, закрыть окно |
| Shift/Ctrl+клик по предмету | добавить или убрать его из группового выделения |

## Разработка

Нужен Node.js 24.14.0 (версия указана в `package.json` → `engines`).

```bash
nvm use 24.14.0
npm install
npm run dev        # сервер разработки
npm run build      # сборка в dist/
npm run preview    # просмотр собранной версии
```

Стек: Vue 3, Vite. Код организован по [Feature-Sliced Design](https://feature-sliced.design/):

```
src/
  app/        точка входа, глобальные стили
  pages/      страница редактора, горячие клавиши
  widgets/    тулбар, холст плана, боковая панель
  features/   действия пользователя: добавление и создание предметов,
              редактирование, масштаб, история, экспорт, варианты расстановки,
              управление комнатами
  entities/   план (модель, геометрия, отрисовка SVG, комнаты) и настройки
  shared/     утилиты и базовые UI-компоненты
```

Подробнее об устройстве — в [CLAUDE.md](CLAUDE.md).

## Публикация

```bash
npm run deploy
```

Команда собирает проект и выкладывает `dist/` в ветку `gh-pages`, из которой GitHub Pages отдаёт сайт (Settings → Pages → Deploy from a branch → `gh-pages`, `/ (root)`).

Расстановка, которую видят при первом открытии (в самой первой, «дефолтной» комнате), лежит в `src/entities/plan/config/saved-layout.json` в виде `{"state": …, "savedAt": …}`. Чтобы заменить её, подставьте в `state` содержимое файла из «Экспорт → Скачать .json», а в `savedAt` — текущее время в миллисекундах (`Date.now()`). Затем опубликуйте заново. Она используется только при самом первом запуске приложения в браузере посетителя — если у него уже есть сохранённые комнаты (или черновик более старой версии приложения новее `savedAt`), они не перезаписываются.
