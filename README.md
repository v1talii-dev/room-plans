# План кабинета маникюра

Интерактивный редактор планировки кабинета: расставляйте мебель на плане комнаты в масштабе, проверяйте проходы и пересечения, выгружайте чертёж.

**Открыть:** https://v1talii-dev.github.io/room-plans/

## Возможности

- План комнаты в сантиметрах с сеткой 10 см, размерами стен, дверьми и окнами.
- Перетаскивание предметов с привязкой к стенам, соседям и сетке (<kbd>Alt</kbd> — без привязки), изменение размеров и поворот ручками.
- Подсветка проблем: пересечения предметов, выход за стены, предметы в зоне открывания двери.
- Расстояния от выбранного предмета до стен и соседей, точный ввод размеров и отступов в панели.
- Каталог мебели (столы, стулья, кресла, комоды, кулер, вешалка и др.) и свои предметы с произвольным названием, формой, размерами и цветом. Свои предметы можно запомнить как шаблоны.
- Двери и окна на любой стене: ширина, положение, сторона петель, открывание внутрь или наружу.
- Отмена и повтор, горячие клавиши, масштаб колесом с <kbd>Ctrl</kbd> и щипком на телефоне.
- Экспорт: картинка PNG, чертёж SVG в масштабе 1:50 для печати, файл расстановки JSON (его же можно загрузить обратно).
- Светлая и тёмная тема, работа на телефоне.

Изменения автоматически сохраняются в браузере. Чтобы перенести план на другое устройство, используйте экспорт и импорт JSON.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | сдвиг на 1 см, с <kbd>Shift</kbd> — на 10 см |
| <kbd>R</kbd> / <kbd>Shift</kbd>+<kbd>R</kbd> | поворот на 90° по / против часовой стрелки |
| <kbd>Delete</kbd> | удалить выбранное |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | дублировать |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | отменить, повторить |
| <kbd>Esc</kbd> | снять выделение, закрыть окно |

## Разработка

Нужен Node.js 24.14.0 (версия закреплена в `.nvmrc`).

```bash
nvm use            # nvm-windows 1.1.x не читает .nvmrc: nvm use 24.14.0
npm install
npm run dev        # сервер разработки
npm run build      # сборка в dist/
npm run preview    # просмотр собранной версии
```

Стек: Vue 3, Vite. Код организован по [Feature-Sliced Design](https://feature-sliced.design/):

```
src/
  app/        точка входа, глобальные стили
  pages/      страница редактора, горячие клавиши
  widgets/    тулбар, холст плана, боковая панель
  features/   действия пользователя: добавление и создание предметов,
              редактирование, масштаб, история, экспорт, варианты расстановки
  entities/   план (модель, геометрия, отрисовка SVG) и настройки
  shared/     утилиты и базовые UI-компоненты
```

Подробнее об устройстве — в [CLAUDE.md](CLAUDE.md).

## Публикация

```bash
npm run deploy
```

Команда собирает проект и выкладывает `dist/` в ветку `gh-pages`, из которой GitHub Pages отдаёт сайт (Settings → Pages → Deploy from a branch → `gh-pages`, `/ (root)`).

Расстановка, которую видят при первом открытии, лежит в `src/entities/plan/config/saved-layout.json` в виде `{"state": …, "savedAt": …}`. Чтобы заменить её, подставьте в `state` содержимое файла из «Экспорт → Скачать .json», а в `savedAt` — текущее время в миллисекундах (`Date.now()`). Затем опубликуйте заново. Черновик в браузере посетителя важнее этой расстановки, если он сохранён позже `savedAt`.
